# 问题二图表契约

统一来源：`artifacts/problem2_final_v1` 的 500 行官方场景 B 最终结果、5300 行候选记录、预注册 12/18/70 case 划分，以及 100 张原始计算图。生成代码逐项校验行数、唯一键、合法性、零退化和关键改善格数。图采用 Python/Matplotlib；数据图版型为独立定量图，流程图为方法示意；文字保持 SVG 可编辑，PNG 600 DPI，另存灰度预览。

|---|---|---|---|
