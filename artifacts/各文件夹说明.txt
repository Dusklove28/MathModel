分类说明
--------

【正式证据】已用于阶段结论、论文材料或全量结果，应保留。
【开发实验】算法开发过程中的探针或候选结果，可重算，不应替代正式结果。
【质检/Smoke】用于检查合法性、缓存、断点续跑或跨环境一致性，不代表全量结论。
【缓存】只用于加速重跑，删除后可以重新生成。
【未完成】失败、预检中止或被中断的运行，不能作为正式结论。

重要原则
--------

1. artifacts/ 中大部分运行产物已被 .gitignore 忽略，不要使用 git add -f 把大目录提交到 Git。
2. 运行 problem2_stage1_baseline_cold_audit 不需要读取任何旧 artifacts；新 output 和 cache 必须为空或不存在。
3. 正式数值结论以官方评估器输出、汇总 CSV/JSON、输入与源码哈希为准。
4. 同一 output/cache 目录只能由一个主进程写入；--workers 是单个主进程内部并行度。
5. “可不上传”不等于建议立即删除；删除前应确认服务器或其他介质已有备份，且不再需要断点续跑。
